iCare Adaptive Chatbot
iCare / DAIS Lab · UW Bothell · 2025–Present

Designed a personality-adaptive chatbot framework that adjusts its conversational persona in real time based on detected user emotions, making mental health AI more personalized and responsive. Currently being extended with a RAG pipeline that grounds responses in knowledge retrieved from DEC-clustered user coping profiles.

  • Engineered a real-time emotion classification module using Sentence-BERT embeddings to detect user affect from conversation context
  • Built a dynamic persona switching system that routes LLM prompts through different personality templates based on emotion state
  • Evaluated chatbot responses across empathy and engagement metrics using both automated scoring and human review
  • Designed the system to be model-agnostic, supporting plug-in of different backbone LLMs
  • Extending with a RAG pipeline that retrieves relevant therapeutic context from a vector store indexed by DEC-derived coping clusters — grounding LLM responses in user-specific behavioral patterns rather than generic prompts

Deep Embedded Clustering
iCare / DAIS Lab · UW Bothell · 2025–Present

Applied unsupervised deep learning to cluster user coping strategies from therapy conversations, enabling more targeted therapeutic AI interactions without requiring labeled training data.

  • Implemented Deep Embedded Clustering (DEC) to learn latent representations of user coping behavior from raw conversation text
  • Decoupled coping mechanism signals from surface-level generative text, reducing noise in downstream LLM conditioning
  • Validated clusters against qualitative clinical frameworks to ensure interpretability and clinical relevance
  • Used cluster assignments to personalize therapeutic interaction styles in the iCare chatbot pipeline
